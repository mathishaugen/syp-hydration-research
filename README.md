# syp Hydration Research

Minimal, dedicated repo powering the daily syp hydration research brief.

This repo contains **only** the research-brief skill and its output — no
financial, legal, patent, or other syp business documents live here. It
exists solely so a scheduled cloud agent can generate the daily brief
without depending on a local machine being on.

- `.claude/skills/hydration-research-brief/SKILL.md` — the skill definition
- `Research Briefs/` — one markdown article per run

The canonical local copy of the skill (used for on-demand/manual runs) lives
in the main syp document drive at
`.claude/skills/hydration-research-brief/SKILL.md`. Keep the two in sync if
you edit one.
